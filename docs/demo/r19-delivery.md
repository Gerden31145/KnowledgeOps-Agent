## 可直接使用的简历项目表述

**KnowledgeOps Agent｜GitHub 驱动的学习验收工具**

技术栈：Nuxt / Vue 3、TypeScript、TanStack Query、NestJS、PostgreSQL、Prisma、BullMQ、LangChain、Docker、GitHub Actions。

基于 GitHub 提交的 Markdown 笔记，提供学习计划、内容验收、理解追问及任务依赖解锁，形成从学习内容提交到验收反馈的闭环。

- 开发计划与验收工作台，通过 URL 恢复任务、历史报告和页签选择，支持固定提交正文、Diff 与引用定位；结合稳定 requestId 和后端幂等，处理回答提交后响应丢失、刷新重发等场景。
- 实现计划生成 SSE 快照恢复，通过订阅批次隔离、版本比较与终态保护防止旧异步结果覆盖；结合 HTTP 校准、轮询兜底和连接清理，支持刷新与断网恢复。
- 打通 GitHub Push 取证与笔记/回答异步验收，使用 Outbox、数据库版本复核和事务提交保护业务结果；通过 Playwright 覆盖闭环与恢复场景，并以 GitHub Actions、GHCR 和 Docker Compose 实现自动验证、手动选版发布及兼容回退。

这是项目内容定稿，不包含未经确认的个人任职时间、用户规模、独立开发比例或性能收益；个人贡献应按真实 AI 辅助开发、手写和可解释范围说明。未修改用户已有 DOCX 简历。
